# C Exam Master (Basic-C-Learning)

Professional Training Course for C Programming.
Built with React, TypeScript, Vite, and Tailwind CSS.

## Features
- **Documentation**: Master the fundamentals.
- **Flashcards**: Memory training.
- **Practice Mode**: Skill building with instant feedback.
- **Exam Simulation**: Final test simulation.

## Getting Started

### Prerequisites
- Node.js installed

### Installation

```bash
npm install
```

### Running the App

```bash
npm run dev
```

### Building for Production

```bash
npm run build
```
